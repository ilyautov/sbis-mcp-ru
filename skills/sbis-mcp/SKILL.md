# СБИС (Saby) через MCP

Ставит сервер `sbis-mcp` из пакета `sbis-mcp-ru`: 45 команд (чтение 19,
запись 21, необратимое 5), каталог собран по справке
`saby.ru/help/integration/api`.

## Особенность транспорта

У Saby один HTTP-адрес на все команды: `POST /service/`, а имя команды
(«СБИС.СписокДокументов») едет в теле JSON-RPC. Сервер это знает, поэтому в
чате вы работаете с обычными именами методов, а не с путями.

## Установка

```json
{
  "mcpServers": {
    "sbis": {
      "command": "uvx",
      "args": ["--from", "sbis-mcp-ru", "sbis-mcp"],
      "env": { "SBIS_SESSION_ID": "<идентификатор сессии>" }
    }
  }
}
```

## Где взять сессию

Команда `СБИС.Аутентифицировать` по логину и паролю сотрудника с правами на
API возвращает идентификатор сессии. Он живёт ограниченное время и обновляется
той же командой. Пароль в сервере не хранится.

## Осторожно

`СБИС.УдалитьДокумент` помечает документ удалённым, а `СБИС.УничтожитьДокумент`
удаляет без восстановления. Обе команды требуют подтверждения, вторая особенно.
