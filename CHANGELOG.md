# Changelog

## [0.3.0] — 2026-09-14

### Изменено (ломает публичный набор инструментов)
- **Чтение и запись разъехались по разным инструментам** вслед за ядром
  schema-mcp-core 0.3.0. Вместо `call_method` и `call_raw` теперь шесть: `call_method`
  (только чтение), `write_method`, `delete_method`, `get_raw`, `write_raw`,
  `delete_raw`. Чтение помечено `readOnlyHint` и больше не спрашивает
  подтверждения; вызов не тем инструментом возвращает `safety_gate` с именем
  нужного в `details.use_tool`.

## [0.2.2] — 2026-09-12

- карточка сервера в MCP Registry не вела на сайт: в `server.json` не было
  поля `websiteUrl`, хотя у moysklad и marketplaces оно стоит. Добавлено.
  Отдельным выпуском, потому что реестр публикуется по тегу и подхватывает
  только то, что лежит в теге.

## [0.2.1] — 2026-09-12

- на странице пакета не было ссылки на сайт: в `project_urls` стояли
  только репозиторий, ишьюс и журнал изменений. Добавлены `Homepage` и
  `Documentation`, человек с PyPI теперь попадает на карту методов.

## [0.2.0] — 2026-09-11

Первый выпуск. Каталог на 45 методов, собран из первоисточника
(справка `saby.ru/help/integration/api`).

- поиск метода словами, описание с параметрами и пагинацией, вызов;
- класс доступа read / write / destructive, запись требует подтверждения;
- кабинеты: ключи вне репозитория, права 600;
- `doctor` для проверки установки без секретов в выводе.
